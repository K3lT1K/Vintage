# Vintage Solo

Одиночная Android-игра на движке Forge. Четыре фиксированные колоды: Mono-White Initiative, Workshop Aggro, Oath of Druids и Doomsday. GPL-3.0.

- [Скачать подписанный APK в ZIP (~191 МиБ)](https://github.com/K3lT1K/Vintage/actions/runs/34482103338/artifacts/10154438646).
- [Полные исходники этой сборки](https://github.com/K3lT1K/Vintage/actions/runs/34482103338/artifacts/10154031346) — ZIP с tar.gz дерева Forge.
- [Сборка и проверки](https://github.com/K3lT1K/Vintage/actions/runs/34482103338).
- [BUILD.md](BUILD.md) — установка и повторная сборка.
- [HANDOFF.md](HANDOFF.md) — проверенное состояние и ограничения.

Распакуйте ZIP и установите `vintage-solo.apk` поверх предыдущей версии. На стартовом экране кнопка **Картинки колод → Скачать** загружает только используемые печатные версии карт четырёх колод, их обратные стороны и нужные жетоны. Общие карты и уже скачанные файлы не дублируются; массовой загрузки каталога нет. После загрузки картинки доступны офлайн. Текстовые карты работают без загрузки изображений.

Поле: земли слева, существа по центру, прочие артефакты и чары справа; ауры остаются со своими целями. Рука веером снизу, меню под шестерёнкой, стек отдельной иконкой. Русский текст всех 84 разных карт колод; названия на английском сохранены, переводы не заявляются официальными.

Бот получил отдельные условия и выбор целей для Gaea's Blessing, Mindbreak Trap и Gitaxian Probe. Doomsday использует одну консервативную стопку через Recall/Lotus/Oracle; добавлена отдельная линия Oracle → Consultation над его способностью, с проверкой UUB, защиты Force of Will и ответов в стеке. Другие стопки Doomsday пока не реализованы. Сила бота против человека не измерялась.

**Проверено:** компиляция; 14 тестов на реальном Forge без ошибок; 20 локальных проверок; подпись APK и целостность всех офлайн-ресурсов. Статус Android-проверки и ограничения см. HANDOFF.

**Не проверено:** полные партии всех матчапов, сравнительный винрейт бота, реальная загрузка изображений на телефоне и эта версия на физическом OnePlus 13 / OxygenOS 16.

GitHub требует вход для скачивания Actions artifacts; срок хранения ограничен. Для повторного получения APK запустите workflow по BUILD.md.

Этот репозиторий хранит проект сборки: `vintage-solo.patch`, `fixes/`, `build_fixes.py` и применяемый последним `presentation.patch`. Workflow восстанавливает Forge на коммите `ce5b0dbf17733847929e990c77274893223e1fa6`. Code → Download ZIP скачивает проект сборки, а полный Forge находится в исходном artifact выше.
