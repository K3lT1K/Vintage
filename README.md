Исправлен немедленный вылет: ресурсы теперь распаковываются в Launcher до входа в LibGDX Activity. Подписи отдельного меню переведены на английский, поскольку кириллица не отображалась встроенным шрифтом.

**Проверено:** сборка, подпись, офлайн-ресурсы; чистая установка и запуск без Wi-Fi/мобильных данных на эмуляторе Android 16 API 36 x86_64; три минуты без падения, возврат после HOME; видимые подписи меню на скриншоте.

**Не проверено:** эта версия на физическом OnePlus 13 / OxygenOS 16; начало и завершение партии; профильная логика и сила бота. Полных партий выполнено 0. Это проверенная сборка с проверенным запуском на эмуляторе, а не полностью проверенная игра.

GitHub требует вход для скачивания Actions artifacts; срок хранения ограничен. Для повторной сборки используйте workflow.

Репозиторий содержит исходный patch, каталог fixes и build_fixes.py. Workflow берёт Forge `ce5b0dbf17733847929e990c77274893223e1fa6`, применяет все исправления и публикует полный исходный архив. Code → Download ZIP скачивает проект сборки, а не весь upstream Forge.
