# Сборка и проверка Vintage Solo

## Установка

1. Войдите в GitHub и скачайте [APK в ZIP](https://github.com/K3lT1K/Vintage/actions/runs/34482103338/artifacts/10154438646).
2. Распакуйте архив, откройте `vintage-solo.apk` и установите поверх предыдущей версии.
3. Запустите Vintage Solo и дождитесь распаковки встроенных ресурсов при первом запуске или обновлении. Обычный режим телефона подходит; авиарежим нужен только для отдельной проверки офлайн.
4. Для иллюстраций: **Картинки колод → Скачать**. Нужен интернет. Очередь ограничена картами всех четырёх колод, обратными сторонами и нужными жетонами. Повторы/готовые файлы пропускаются. Массовый каталог не загружается.
5. После завершения изображения берутся из кеша. Без загрузки можно оставить **Текстовые карты**.
6. Выберите свою колоду и колоду бота, нажмите **Начать партию**.

APK подписан отладочным ключом Forge uber-apk-signer. Package `forge.vintage.solo`, min SDK 26, target SDK 35. Подпись и содержимое проверяет CI; SHA256SUMS и verification.txt лежат рядом с APK в архиве.

## Короткая проверка на OnePlus 13

- Откройте игру и начните партию, проверьте руку, землю слева и артефакт/чары справа.
- Откройте шестерёнку, журнал и стек; удерживайте карту для увеличения.
- Проверьте остаток маны: получите три, потратьте одну и посмотрите на оставшиеся две **в том же шаге/фазе**; ограничения источника и налоги учитываются по правилам.
- Сверните игру и вернитесь. Попробуйте завершить партию.
- Скачайте изображения, затем отдельно проверьте их без сети.

При ошибке пришлите скриншот/видео, колоды, карту и действие перед ошибкой. При вылете укажите этап: распаковка, главное меню или партия. Восстановление партии после уничтожения процесса не реализовано.

## Повторить GitHub Actions

Откройте [workflow](https://github.com/K3lT1K/Vintage/actions/workflows/vintage-android.yml) → **Run workflow** → **main** → **Run workflow**. Откройте новый запуск; после зелёного результата в **Artifacts** скачайте **vintage-solo-apk**. Полные исходники — **vintage-solo-source**, логи сборки — **vintage-solo-diagnostics**, скриншоты/logcat — **android16-startup**.

Workflow также запускается при push в main/codex/vintage-apk. Для правок только документации используйте `[skip ci]`. GitHub artifacts имеют ограниченный срок хранения.

## Воспроизвести локально на Linux

Нужны Git, JDK17, Python3.11+, curl, tar, unzip и Xvfb при отсутствии дисплея. Скрипт bootstrap не использует apt/sudo.

```bash
git clone https://github.com/K3lT1K/Vintage.git project
git clone https://github.com/Card-Forge/forge.git forge
cd forge
git checkout ce5b0dbf17733847929e990c77274893223e1fa6
git apply --check ../project/vintage-solo.patch
git apply ../project/vintage-solo.patch
cp -a ../project/fixes/. .
python3 ../project/build_fixes.py
# После ознакомления и согласия с условиями Android SDK:
ACCEPT_ANDROID_SDK_LICENSES=yes bash tools/vintage-solo/bootstrap.sh
source .vintage-tools/env.sh
xvfb-run -a bash tools/vintage-solo/build.sh
python3 tools/vintage-solo/check_apk.py
```

Результат: `dist/vintage-solo/vintage-solo.apk`. При использовании полного исходного архива уже применены patch и build_fixes; повторно их применять не нужно.

Зафиксированы Maven 3.8.1, Android CLI 11076708, Android platform35/build-tools35.0.0, Forge Android Maven plugin4.6.2. Upstream timestamps/транзитивные зависимости не гарантируют побитовой воспроизводимости.


## Что проверяет CI

- 20 локальных проверок, синтаксис 31 Java-файла, состав четырёх колод по 60 карт и B/R по закреплённым данным Forge.
- Наличие русских текстов всех 84 разных карт; сохранность мана-символов.
- Полную компиляцию с Checkstyle.
- 14 тестов на реальном Forge: пять для маны/перевода, пять для новых правил карт и стопки Doomsday, один для ограниченной очереди изображений и пропуска кеша.
- Подпись APK, launcher, DEX, native LibGDX; CRC и точное соответствие офлайн-ресурсов.
- Установку и запуск на эмуляторе Android 16 API36 x86_64 без Wi-Fi/данных, возврат после HOME, отсутствие обнаруженных FATAL/ANR; сохраняет скриншоты меню и партии.

Фактический итог Android-прогона и ограничения — в [HANDOFF.md](HANDOFF.md). Полных партий и сравнительного теста силы бота пока нет. Передача изображений из интернета на физическом телефоне пока не проверена.

`presentation.patch` применяется последним из `build_fixes.py`; повторно применять его не нужно. Doomsday использует один консервативный план, а Demonic Consultation теперь разыгрывается над собственной способностью Оракула с проверками маны и защиты. Русские переводы пользовательские; английские названия сохранены.
