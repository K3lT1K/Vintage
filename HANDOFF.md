Пользователь: OnePlus 13, OxygenOS 16, немедленный вылет с сетью и без неё.
Повторено на Android 16 API 36 x86_64 emulator: run 34242387109, job 102115585617.
Причина: Main extends AndroidApplication начинал асинхронную распаковку и возвращался до инициализации LibGDX; onResume проглатывал исключение и не достигал Activity.super.onResume, Android завершал процесс с SuperNotCalledException.

Исправление d939a30ab510d2f69b2198d589dd2d1651f7c585: распаковка в обычной Activity Launcher с индикатором, затем Main синхронно инициализирует LibGDX. Сохранён фоновый I/O. Не изменены правила игры/бот.
Run исправленной сборки: https://github.com/K3lT1K/Vintage/actions/runs/34242705450 — пока выполняется. После apk должен стартовать job startup: офлайн-запуск, 180 секунд наблюдения, HOME, повторный вход; логи/скриншоты в android16-startup.
Пример исходного исключения: ci/evidence/android16-original-crash.txt.

При локальной сборке после git apply обязательно cp -a ../project/fixes/. . перед python3 ../project/build_fixes.py. Workflow уже делает это. Полный source artifact содержит применённые fixes.
